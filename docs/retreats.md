# Retreat Pages Guide

Эта инструкция описывает текущую V2-архитектуру ретритов. TypeScript-файлы в `shared/retreats/` задают начальный
фиксированный набор, а после seed рабочие данные хранятся в PostgreSQL и редактируются через admin API.

## Где лежат данные

- `shared/retreats/cirali.ts` — ретрит Чиралы
- `shared/retreats/nepal.ts` — ретрит Непал
- `shared/retreats/mountains.ts` — горный ретрит
- `shared/retreats/types.ts` — типы контента
- `shared/retreats/index.ts` — сборка, локализация, фильтрация и поиск ретритов

Главная секция ретритов и детальная страница читают `/api/retreats`, используя `@shared/retreat-content` как
типизированный статический fallback. API не позволяет добавлять или удалять ретриты.

## Как устроен ретрит

Каждый ретрит — это объект `RetreatSeed`:

- `title`, `location`, `startDate`, `endDate`, `dateLabel`, `price`, `bookingUrl`, `coverImage`, `status`
- `translations` для RU/EN полей верхнего уровня
- `blocks` для длинного контента детальной страницы

Поддерживаемые блоки:

- `paragraph` — обычный абзац
- `heading` — подзаголовок
- `image` — изображение по имени файла
- `callout` — выделенная плашка
- `countdown` — таймер/ценовой блок

Порядок блоков задаётся через `sortOrder`.

## Как редактировать

Для рабочих изменений используйте admin API из `docs/admin-api.md`. Файлы в `shared/retreats/` меняйте только когда
нужно изменить исходные данные для новой установки.

Для RU-версии меняйте поля внутри `translations.ru`. Для EN-версии меняйте базовые поля или `translations.en`, если оно используется.

После правки seed-файлов:

```bash
npm run check
npm run build
```

Повторный seed не перезаписывает ретриты, которые уже есть в БД, поэтому опубликованный контент не будет случайно
заменён содержимым TypeScript-файлов.

## Статусы

- `active` — ретрит доступен
- `archived` — ретрит остаётся видимым, но считается прошедшим/недоступным
- `draft` — черновик

Главная секция V2 всегда строит три карточки в фиксированном порядке: Непал, Чиралы, горный ретрит. Доступность кнопки определяется статусом и датой окончания.
