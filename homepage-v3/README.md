# Homepage V3

Реализация от 10 октября 2026 по согласованному `layout/full-page-v2.png`. Финальная секция взята из первого макета `layout/full-page-v1.png`. Рабочий каталог — этот worktree; первоначальные PNG в основном checkout не изменялись.

## Запуск

Из корня репозитория:

```sh
npm ci
npm run dev:client -- --host 127.0.0.1
```

Открывать во внутреннем браузере Codex: `http://127.0.0.1:5000/` или `/homepage-v3`.

```sh
npm run check -- --incremental false
npm run build
```

## Структура

- `HomepageV3.tsx` — сборка семи секций, меню, RU/EN и якорная навигация.
- `useIntroMotion.ts` — общая GSAP-сцена hero → about → classes.
- `sections/` — независимые React-компоненты и CSS Modules.
- `media.ts` — типизированные URL, размеры и alt реальных фотографий.
- `landing.json` — согласование, композиция, контентный снимок, ресурсы и фактическое motion-поведение.
- `layout/` — макеты и раскадровка; `layout/sections/` — референсы отдельных блоков.
- `assets/real-photos/source/` — локальные неизменённые исходники New Assets. Полноразмерные оригиналы не отправляются в публичный репозиторий; для повторной подготовки передайте их каталог в `assets/real-photos/prepare-real-photos.py`.
- `assets/real-photos/ready/` — оптимизированные sRGB/WebP; происхождение и хеши в `manifest.json`.
- `client/public/assets/landing-v3/` — ресурсы, используемые приложением. Все фотографии реальные; новых сгенерированных фотографий нет. Hero становится ч/б через CSS.

## Поведение

Desktop от 1000×680: три первых блока образуют одну закреплённую сцену на 425vh скролла. Нерегулярная мозаика из 10 уникальных фото увеличивается и разлетается, раскрывая подход. После паузы фотографии и текст улетают, появляются занятия. Прокрутка нативная, анимация обратима. На узких и низких экранах — естественный поток и облегчённый разлёт; при reduced motion всё статично и доступно.

Ретриты: ровно три записи из `shared/retreat-content`, ручная карусель со свайпом, стрелками, клавиатурой и счётчиком. Доступность определяется текущими локальными данными и датами; серверный запрос не нужен.

Практика: существующий ролик `Z_AabfLhaHo` из контента сайта загружается по нажатию. Реальный снимок на обложке не является кадром ролика. Под плеером остаётся прямая ссылка на YouTube.

«37 практик бодхисаттвы»: автоматически меняются три имеющиеся смысловые выдержки — практики 1, 3 и 10. Это не полный текст всех 37 практик. Интервал 8 секунд; плавный fade/slide слева направо длится 1 секунду. Видимого номера и ручных кнопок нет. Таймер работает только при видимой секции и останавливается в фоновой вкладке и при reduced motion.

Финал: композиция v1 с тремя направлениями и крупным Yogermeisters. Тексты занятий, цены и видео используют существующий `landing-v2/content.ts`, ретриты — общие записи проекта. Макет не используется как растровый фон сайта.

Проверки и изображения результата: `qa/`.

Последняя правка: все 10 фото hero уникальны, включая `ZVC03615.jpg` и фото у водопада. Размеры и пропорции кадров различаются, нижняя стрелка удалена. Шапка остаётся fixed и использует полупрозрачный `mix-blend-mode: difference`.
