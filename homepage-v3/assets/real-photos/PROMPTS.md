# Homepage V3 — комплект реальных фотографий

Дата подготовки и визуального просмотра: 10 октября 2026.

## Задание

Подготовить один повторно используемый комплект из всех 10 реальных фотографий пользователя для hero, About и classes. Сохранить оригиналы, исправить только EXIF orientation, привести цветовой профиль к sRGB и уменьшить крупные кадры до длинной стороны 1800 px. Выход: отдельные WebP, quality 84, без апскейла, изменения лиц, ретуши, дорисовки и удаления объектов. Чёрно-белое отображение цветных фото выполняет CSS страницы.

ImageGen не вызывался; генеративных промптов в этом задании нет.

## Фактический workflow

В проекте не найден отдельный скрипт оптимизации изображений или зависимость Sharp. Использована уже доступная Pillow с ImageCms. Воспроизводимый скрипт сохранён рядом с комплектом:

```sh
python3 homepage-v3/assets/real-photos/prepare-real-photos.py '/Users/daniel/coding/Yogermeisters/homepage-v3/new assets'
```

Повторная подготовка из сохранённых локальных оригиналов:

```sh
python3 homepage-v3/assets/real-photos/prepare-real-photos.py
```

Все команды выполнены из `/Users/daniel/.codex/worktrees/1041/Yogermeisters`.

Обработка каждого файла: побайтное копирование в `source/`; чтение и применение EXIF orientation; преобразование встроенного ICC в sRGB либо явная маркировка нетегированного RGB как sRGB; уменьшение LANCZOS до max 1800 px без апскейла; WebP quality 84, method 6, встроенный sRGB ICC. EXIF не переносится в runtime-файлы, ориентация уже применена к пикселям. Цветные оригиналы не переводились в ч/б. Кадрирование остаётся задачей CSS секций.

`manifest.json` содержит исходное имя, абсолютные пути, размеры, вес, SHA-256 оригинала и WebP, alt ru/en, objectPosition и назначение. `heroTiles` — предложенный порядок 4×3 из 12 реальных повторных кадров ближайших к композиционному референсу. Для крупных деталей лица, рук и волн требуется CSS sizing/кадрирование под фактический слот; позиции в manifest являются стартовыми рекомендациями.
